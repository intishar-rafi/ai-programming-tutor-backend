# budget_tracker

## Goal
A command-line tool that keeps track of monthly expenses against a budget.

## Features
- Keep a list of expenses, each with a category and an amount
- Show the total spent and the remaining budget
- Show the total spent per category
- Let the user add a new expense by typing a category and an amount
- Warn the user when the budget is exceeded

## Out of scope
- Saving expenses to a file
- Charts or a graphical interface
- More than one month at a time

## Constraints
single main.py, under 1000 lines, standard library only
